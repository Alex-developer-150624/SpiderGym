¿Qué es SpiderGym?

SpiderGym es un proyecto de gimnasio inteligente en el que los usuarios pueden identificarse en las máquinas mediante una tarjeta NFC o un código QR.

La idea es que cada entrenamiento quede registrado de forma sencilla y que el usuario pueda consultar después información sobre sus series, repeticiones, pesos y descansos.

¿Cómo funciona?

  1. El usuario se identifica mediante NFC o QR.
  2. La máquina reconoce al usuario.
  3. Se registra el ejercicio realizado.
  4. Se guardan las series, repeticiones y peso.
  5. Los datos se almacenan en el sistema.
  6. El usuario puede consultar su progreso más adelante.

Objetivo del proyecto

El objetivo de SpiderGym es facilitar el seguimiento de los entrenamientos y evitar que el usuario tenga que apuntar todo manualmente.

También se plantea como un proyecto que puede crecer en el futuro con funciones como rutinas, estadísticas, logros o recomendaciones automáticas.
