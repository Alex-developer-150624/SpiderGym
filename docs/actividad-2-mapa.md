# Actividad 2. Mapa inicial de información
```text
Gimnasio
└── Máquinas
    └── Máquina concreta

Usuario
└── Entrenamientos
    └── Ejercicios
        └── Series
            ├── Peso
            ├── Repeticiones
            └── Descanso
```
En SpiderGym he identificado varios elementos principales: usuarios, gimnasios, máquinas, ejercicios, entrenamientos y series. 
Estos elementos se relacionan porque cada usuario realiza entrenamientos en un gimnasio y utiliza máquinas para hacer ejercicios.
Cada entrenamiento contiene varias series, en las que se guardan datos como el peso, las repeticiones y el descanso.
